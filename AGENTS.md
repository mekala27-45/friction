This file is the single source for agents and people. CLAUDE.md and .github/copilot-instructions.md
point here.

```
uv sync --extra spark          # Python 3.12; Java 21 for Spark
export FRICTION_ALLOW_TEST_SALT=1
```

## Rules

- No workspace call from the build machine. Commit a request under requests/ (docs/runbooks/requests.md).
- No token, card number, CVV, address or raw IP anywhere: repository, logs, exports, the site.
- No number in a document by hand. Documents render from results/manifest.json (scripts/build_manifest.py).
- No feature reads an event at or after the one it describes. A new feature needs its as of test.
- No task appends without a key or a stated range.
- No language model in a decision.

## Files an agent must not edit

- uv.lock, data/sources.lock.json, data/replay.lock.json, evaluation/plan.lock: regenerated by their
  scripts, never by hand.
- evaluation/plan.yaml and evaluation/hypotheses.yaml: registered; a change needs a dated DECISIONS.md
  entry and a new lock, and invalidates every graded number.
- evaluation/rba_published.yaml: transcribed from the data set repository.
- results/ files promoted from the workspace: only scripts/promote_results.py writes them.
- Rendered documents (README.md, RESULTS.md, report/briefing.md, docs/models, docs/validation): edit the
  template under docs/templates or report/templates instead.
